# Changelog

All notable changes to Lavenders are documented here.

## 1.0.0 - 2026-08-01

Initial public release.

### Features

- Local, offline-first two-week calendar with SQLite storage.
- Create, edit, and delete events with date and time selection.
- Finnish and English interface languages.
- Lavender light and dark themes.
- Optional weekend visibility.
- One-click application updates through GitHub Releases and Velopack.

### Data and privacy

- Events and preferences remain on the user's computer.
- Internet access is used only for update checks and user-approved downloads.
